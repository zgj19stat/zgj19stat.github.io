# Guojun Zhu — Personal Homepage

Source for [zgj19stat.github.io](https://zgj19stat.github.io/), built with Jekyll and the Academic Pages theme.

## Content to update

- `_pages/about.md` — homepage biography and research interests
- `_pages/publications.md` — manuscripts and publications
- `_pages/talks.md` — talks and posters
- `_pages/cv.md` — education, teaching, and awards
- `_config.yml` — profile, links, and site-wide metadata
- `_data/navigation.yml` — top navigation
- `images/profile.png` — profile photo
- `files/` — public slides and documents linked from pages

The `_includes`, `_layouts`, `_sass`, and `assets` directories contain the Jekyll theme implementation and should be retained while this site uses Academic Pages.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://127.0.0.1:4000/`. GitHub Pages publishes the `master` branch at `https://zgj19stat.github.io/`.
